# 若叶睦

若叶睦有月之森制服和红贝雷帽演出服两套衣装。两套共用定稿里的脸型、浅金褐色眼睛和灰薄荷长发。

![若叶睦](portrait.png)

在「伙伴设置」中选择若叶睦。她会拨弦校音、用掌侧制音、擦弦、翻谱，也会照看窗边的黄瓜。和后藤独合奏时，她示范两个音，停下来等对方接上。

右击睦，选择「换衣服」，可以直接换上另一套。演出服有独立的扶帽、整理领饰和谢幕动作。她会把拨片藏在帽檐下，摊开提示单核对，偶尔举起双臂，笑着说「全都不会弹！」。两套衣装各自记住日程，继续照看同一株黄瓜。

基础图集每格 192 × 208 像素。九套基础动作占 57 格，另有十六个注视方向。向左、向右走各有八帧。人物转身时，发夹和胸章也随朝向改变。

`actions` 目录包含 21 张六格透明动作图，共 126 格。两条合奏图分别用于伙伴在睦左边和右边的情形。她会转头看向对方，两套图都用右手拨弦。细节与触发时机见仓库根目录的《桌宠动作设计规范》。

演出服在 `outfits/stage` 中，另有 73 个基础与注视画格以及 25 张六格动作图。制服 199 格，演出服 223 格，共 422 个不同画格。

将整个目录内的文件和 `actions` 一起压成 ZIP，即可从「伙伴设置 → 导入与切换其他角色」导入。

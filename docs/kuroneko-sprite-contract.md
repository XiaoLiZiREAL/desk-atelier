# 黑猫素材与接入验收

- 基础图集和静态形象都齐全后才会出现在角色选择器。其他五位不引用黑猫扩展。
- 每个成品格是 192×208 的独立完整人物，统一接地基准，不拼接身体。基础图集是八列九行或十一行；主动作图集按现有六格格式；窗沿及专属动画用七列格式，按现有窗台基准落位。源概念图不计入发行体积。
- 专属图集使用 `kuroneko-interaction-<pose>-<target>.png`，pose 为 stand 或 seat。比如 `stand-hair`、`stand-hem`、`seat-leftshoe`。招牌互动有两份 `kuroneko-interaction-manuscript.png`（趴着改稿、邀请、指稿、悄悄抬眼、收回）及 `kuroneko-interaction-manuscript-entry.png`（坐姿转身撑稳到趴下），以及 `kuroneko-interaction-manuscript-exit.png`（合稿、起身、收稿、复位；单独绘制而不是倒放）。
- `kuroneko-zones.txt` 每行填写 `姿势 目标 x y 宽 高`，例如姿势是 standing、seated 或 offer。目标值是 Hair、Collar、Cuff、Hand、Manuscript、LeftShoe、RightShoe 或 Hem。坐标以 192×208 为准；透明像素一定不命中，后写的区域优先于前写的区域。坐在窗台时仅使用稳定坐姿的区域，其他姿势不会误用。
- 专属剧情只在对应的角色与姿态下有效；拖拽、双击、被盖住、便签和专注、打开工具会让出。只在需要时载入专属帧，换角色后清除缓存。邀请必须有完整衔接图集和点击区域，缺一项不触发。
- 验收：普通角色行为不变；单击只接受一次；双击中的第一次松手不触发单击；拖拽、失去鼠标捕获、遮挡、不同稿本、到期、透明区都不触发；忽略邀请有自然收尾。实际浅色/深色桌面与实际缩放下检查。最后量发行 ZIP 增量与运行内存，再决定分包。

## 第一季角色动作复核

| 场景 | 目前接入与素材 | 验收重点 |
| --- | --- | --- |
| 站姿交互 | 发饰、领口、袖口、手和外裙面的独立绘制动作；袖口有视线、缩手与独立停顿 | 轻点一次就登记；双击维持菜单；不读取换帧后原像素 |
| 窗沿 | 普通坐姿的鞋尖区域按六个实际帧校准；有侧躺、伏着、专属交替晃腿和邀稿 | 两脚分别可点；遮挡、移动或换角色后终止旧互动 |
| 邀稿 | 趴下、举稿、等回应、鼠标来到页边后的视线变化、放低稿本、合稿和坐回都有相应整帧 | 页面可点范围在变化中稳定；不点时自然收尾；拖拽、遮挡和失焦不触发接受 |
| 桌面休息 | 不再用六帧站姿循环冒充，使用独立的松肩、合眼、悄悄睁眼和复位 | 待机与休息动作能肉眼区分 |
| 专注、写作 | 有桌面、窗沿和入场图集；写作项目按提纲、改稿、装订三阶段接入 | 实际输入、暂停与恢复仍需端到端走一遍 |
| 便签、听歌 | 收和还便签在站姿与窗沿各有整帧；还便签仅在光标靠近时临时收手；听歌与跟唱使用分别绘制的全身动作 | 听歌与器乐段不同速度，不抢番茄钟；暂停、切歌与实机接收需复测 |
| 视线 | 十六向全身视线新增在第十、十一行；站姿等光标停留后才短暂回应 | 各方向有效、随方向稳住后才转眼，脚底位置不跳 |

此表中的“接入”仅指代码路径和程序素材，不替代 Windows 的低缩放、双屏和实际鼠标测试。

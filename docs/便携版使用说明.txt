窗边手记　1.3

双击「窗边手记.exe」，桌面右下角就会出现蕾姆。她会自己喝茶、写字、找凳子休息，也会出个小谜题。第一次相处，可以先什么都不点，等她自己行动。

右击小人
番茄钟、听音乐、便签和伙伴设置都在右键小菜单里。「礼物」也可以直接从右键菜单打开。打开哪一项，就在她身旁显示对应的小卡片。点桌面、点其他应用、按 Esc 或点 × 都能收起卡片。番茄钟继续计时，便签草稿可以回来接着写。拖动小人可以换位置。托盘菜单可以找回收起的桌宠，也可以完全退出。

认识三位伙伴
蕾姆用杯碟喝茶，红莉栖会翻开笔记本。要见史蒂夫，右击 → 伙伴设置 → 史蒂夫。他使用 Java 版 1.8 经典宽臂造型，会自己用镐采矿、捡起掉落物、看地图和喝水。三位伙伴的生活顺序分别保存。
主动活动频率有「安静一些」「自然」「活泼」三档。专注、全屏或播放音乐时会避开游戏邀请。启用「安静陪伴」会暂停主动活动和桌面字幕。

桌边的小把戏
看到小人拿出纽扣或绿宝石，等她藏好，再决定要不要猜。想参与就点桌面上的一个小盒子；继续做自己的事也可以，她会自行揭晓、收拾。生活手记会记下这些小事。点小人背后露出的纸签，每页可以读一条记录。点「上一页」或「下一页」时，纸签会随机换成另一种颜色，共有黄、蓝、红三色。

让她陪你听歌
右击 → 听音乐，默认自动识别，也可以指定网易云音乐、QQ 音乐或酷狗音乐。点击 18 秒内置演示，可以先看跟唱动作和字幕。
播放真实歌曲时，程序会尝试从 Windows 媒体会话和播放器公开的控件读取歌曲、播放状态及当前歌词。可开启播放器的桌面歌词；若文字是画出来的，在听音乐卡片的歌词设置里开启「读取播放器的画面歌词」。识别只针对该播放器的歌词浮窗，在本机处理。某些版本不提供可读取的窗口画面，或无法区分两行时，可以切成单行桌面歌词，或改用 LRC。
本地支持导入、粘贴带时间标签的 LRC，也可指定歌词目录，常见文件名为“歌手 - 歌名.lrc”或“歌名 - 歌手.lrc”。可选的联网匹配会向 LRCLIB 发送曲名、歌手等匹配信息。播放器提供进度时，暂停、拖动和切歌会更新字幕；只有曲名时可手动校时。偏移以 0.5 秒为步长，正值让歌词提前。

把东西交给桌宠
从支持拖放的软件选中一段文字，拖到桌宠身上就能存为便签。试试「10分钟后提醒我拿外卖」。把文件拖给小人，身旁就会出现一个小背包。点背包可以查看和打开收藏的文件，也支持文件夹和网址。背包保存原位置，移出最后一项后会收起。程序完全退出期间到期的提醒，在下次启动时补发。

一起装收音机
在番茄钟里设定时长，开始、暂停或继续。每完成一轮专注会装好一个零件。完成三轮后，从番茄钟的「专注记录 → 去小屋听歌」可播放内置小调，也可以选本地音乐。

送一间小屋
在右键菜单的「礼物」里署名、写卡片，导出 .deskpet 发给朋友。收到的文件可以拖到小人身上，先预览再收下；收下后会应用礼物里的房间布置。便携包附带一份「窗边来信.deskpet」，可以直接试。

带上更多角色
「伙伴设置 → 导入角色 ZIP」支持含 pet.json 与透明动作图集的角色包。完整生活动作可以按随包的《桌宠动作设计规范》制作。自己的数据保存在 %LOCALAPPDATA%\DeskAtelier。换电脑时先退出程序，再复制这个文件夹。本地音乐和背包文件需要在新电脑上有相应文件。

运行环境
Windows 10 1809 或更新版本、Windows 11，.NET Framework 4.8 或更新版本。无需 ChatGPT 账号。基础功能、角色和内置音乐均可离线使用。

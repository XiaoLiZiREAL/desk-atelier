窗边手记　1.12.0

启动与升级
解压便携 ZIP，双击「窗边手记.exe」。桌面右下角会出现蕾姆。升级时先右击旧版的托盘图标并选择「退出」，再启动新版。程序需要 Windows 10 1809 或更新版本、Windows 11，以及 .NET Framework 4.8 或更新版本。无需 ChatGPT 账号。

右键菜单
右击小人可以打开番茄钟、便签、礼物和伙伴设置，也可以切换听音乐。拖动小人可以换位置。点桌面或其他应用会收起普通工具卡，也可以按 Esc。托盘菜单能找回收起的桌宠。

番茄钟
打开「番茄钟」，按住圆环顺时针拖动增加时长，逆时针缩短。一圈是 60 分钟，范围为 1 至 180 分钟。用鼠标滚轮可以逐分钟微调。点「开始专注」后可以收起卡片，再打开便能查看倒计时、暂停或继续。

开始专注后，六位角色都会安静做自己的事，不另设开关。若安装独立的史蒂夫专注动画包，史蒂夫会沿洞道找矿；蕾姆备好两杯茶，红莉栖研究微波炉，后藤独练琴，睦做叶片书签，黑猫安静整理稿本。暂停会保留当前动作。到点不弹专注通知，便签提醒照常。安装扩展：打开「伙伴设置 → 史蒂夫专注动画（可选）」选择单独的 Steve-Focus ZIP；不需要重新导入普通史蒂夫人物包。

听音乐
「听音乐」是开关，首次默认开启。可识别汽水音乐、网易云、QQ 音乐、酷狗、酷我、咪咕、洛雪音乐助手和 YesPlayMusic 的 Windows 客户端。只有歌名时显示歌曲卡片，只有音频活动时显示正在发声的播放器。有同步歌词时，字幕随播放、暂停、跳转和切歌更新。关闭开关即可停止识别并收起字幕。
部分播放器版本只公开曲名。可以开启播放器自己的桌面歌词，或在 Windows 的「音乐」文件夹放入带时间标记的「歌手 - 歌名.lrc」，后者需要播放器提供进度。升级会继续使用原先指定的歌词目录、已导入的歌词和缓存。
听歌时，波奇在前奏和间奏会轻拨琴弦，到了歌词才开口。逐词歌词可标明人声的开始与结束。只有逐句时间时，小人会在相隔较久的两句之间放松，字幕仍然保留。只有歌名时会安静听歌。
在 Google Chrome 里用平时登录的账号打开 music.163.com 并播放即可。桌宠会核对底部播放栏。只有歌曲信息时会显示歌名和可用的歌手信息，小人随歌而动。如果浏览器只提供音频活动，会显示「浏览器正在播放音频」。几个标签同时出声时，如果后台切歌后桌宠跟到了直播或视频，点一下原来的网易云标签即可重新识别。
Chrome、Edge 也可在 QQ 音乐独立播放器、酷狗播放页、酷我、咪咕官方网页和千千音乐独立播放器核对播放栏。各站点公开的字段、登录和试听条件可能不同。其他网页有系统媒体会话时，桌宠也可读取。汽水音乐可以使用 Windows 客户端，也支持官方歌曲分享页试听。页面公开当前歌词时，小人会跟着网页的字幕唱。
右击 → 伙伴设置 → 歌词隐私，可单独开启或关闭两项功能。「联网匹配同步歌词」向 LRCLIB 发送曲名、歌手和时长。「识别播放器的歌词画面」只在本机读取播放器的歌词浮窗。新安装默认两项都关，升级保留原来的选择。

便签
右击 → 便签，直接在纸上写，内容会自动保存。点右上角的折角翻到下一张，按住 Shift 再点可翻回上一张。翻到空白页就能新写一张，每次翻页都会从黄、红、蓝中换一种纸色。点左上图钉，切到其他应用时这张便签仍会置顶，再点可取消。右下垃圾桶删除当前页，可以撤销删除。
把一段文字拖到小人身上也会存为便签。「10分钟后提醒我拿外卖」这样的文字会生成带时间的提醒。程序退出期间到期的提醒会在下次启动时补发。

把便签交给小人
在便签顶边按住「递给伙伴」，拖到小人身上松手，也可以直接点击这个入口。小人会做出收纸动作，原页仍在便签册中，置顶的便签会留在桌面。
便签会从文字中识别时间。比如「半小时后看烤箱」「拿快递，明天下午三点提醒我」「下周一上午九点开会」。单写「10分钟」也会从递纸时开始计时，写「开会半小时」则可以当普通记录。只写钟点时，使用下一次到达这个时刻的时间。具体以纸底的预览为准。
写「晚点提醒我」或同一张纸出现多个可能的时间时，递纸会出现小卡片。选好日期、时间并点「定时递回」，或点「只保管」。任意文字都可以点纸底的小钟手动设时间。修改手动定时便签的正文会保留原定时间，写入新的明确时间后会按新时间提醒。
到点后，小人旁边会出现纸条。点便签文字，打开原来的那一页。点「10 分钟后」，小人会暂时收起它。若有多张同时到期，先递回最早的一张。退出时还没收的纸和关机期间到期的纸，下次启动后都可以收取。
打开便签，从文件夹或桌面按住文件拖到纸上即可添加附件。未置顶的便签会在拖动期间临时浮到前面，松手后恢复原来的图钉设置。普通点击外部仍会收起便签。可附多个文件，到点时点曲别针会直接打开第一个，点纸条则可以挑选。便签保存原文件位置，文件移动后需重新拖入。
写「每周五下午四点交周报」「每晚八点练琴」或「每个工作日早上九点开会」，再把纸递给小人。也可在小钟里选择重复频率。工作日按周一至周五计算。错过好几次只补递一张，收下后按原来规定的时间再提醒。

背包与礼物
把文件或文件夹拖给小人，身旁就会出现小背包。点背包可打开收藏，也可以收藏网址。背包保存文件的原位置，移出最后一项后会收起。
在右键菜单的「礼物」里署名、写卡片，导出 .deskpet 发给朋友。收到的文件可以拖给小人预览，收下后会应用里面的房间布置。便携包中的「窗边来信.deskpet」可以直接试。

六位伙伴
黑猫已内置，在「伙伴设置 → 黑猫」选择。桌面上可以单击发饰、领口、袖口和露出的手指，坐在窗沿时可以点左右鞋尖。她举起稿本时，把鼠标移到稿本上，再单击即可一起看。不点时她会自己收稿。双击仍能打开工具，拖放照常。
选择若叶睦后，右击她，点「换衣服」，再选「月之森制服」或「红贝雷帽演出服」。重新启动后她会穿着上次选择的衣服。演出服有扶帽、整理胸针、谢幕和「全都不会弹！」彩蛋，接便签、听音乐和双人合奏也有单独的姿势。
右击小人打开「伙伴设置」，点「若叶睦」即可选择她。睦会自己校音、擦弦、翻谱和练习制音。有时她会翻看黄瓜叶，过些时候绑藤、摘瓜。只有曲名时，她会轻点手指数拍。
想见《孤独摇滚！》的后藤独，右击小人打开「伙伴设置」，点「后藤独」。她会自己练吉他、喝茶、藏拨片和休息。开启「听音乐」后，播放器提供同步歌词时她会随曲跟唱。
蕾姆会端杯喝茶，红莉栖会翻开笔记本。要见史蒂夫，右击 → 伙伴设置 → 史蒂夫。他使用 Java 版 1.8 经典宽臂造型，会用镐采矿、捡起掉落物、看地图和喝水。看见小人拿出纽扣或绿宝石时，可以猜一个小盒子，也可以等他自行揭晓。
「伙伴设置」可调主动活动频率。启用「安静陪伴」会暂停主动活动和字幕。也可从设置导入含 pet.json 和透明动作图集的角色 ZIP，角色制作要求见随包的《桌宠动作设计规范》。
新的小动作也会自己出现。波奇会捡拨片、偷练谢幕。蕾姆会叠手帕、擦桌边。红莉栖会转笔、在白板上推演。史蒂夫会钓鱼、垫方块再拆下来，偶尔拉弓或举剑格挡。史蒂夫的手臂和腿沿肩、髋整体转动，接纸时像在游戏里拿起一张纸或地图，听音乐时沿用待机和转头。
伙伴独自做事时可以暂时放一放。双人来访被打断时会结束这一轮。短暂拖动、打开工具、听歌或接纸后，还在附近的同一位伙伴会从刚才的动作接下去。切换伙伴、隐藏桌宠或长时间离开后，会开始下一件事。
每位内置伙伴都有一件会花几个小时分段完成的事。波奇练一段旋律，蕾姆缝兔子，红莉栖装电路，史蒂夫种小麦，若叶睦照看一株黄瓜，黑猫分阶段整理自己的小说。半成品的进度随角色保存。可以照常退出，下次见面时再看他动手。
平时还可能遇到三组合演。睦会给波奇示范两个音，再等波奇把乐句弹完。史蒂夫会捡回波奇掉落的拨片，蕾姆会接住红莉栖飘走的纸再递回。选其中任意一位当伙伴都能遇到。

带走存档
自己的数据保存在 %LOCALAPPDATA%\DeskAtelier。换电脑时先退出程序，再复制这个文件夹。背包引用的文件和自己指定的歌词目录也需要在新电脑上可访问。

# 专注陪伴

从现有番茄钟开始，不新增开关。计时是原来的本地计时；动画不会推进个人项目、修改剪贴板或录下用户的声音。

| 牧濑红莉栖 | 翻盖手机控制微波炉，检查香蕉并记录结果。窗沿版偶尔有绿色香蕉结局。 |
| 蕾姆 | 保留原来的两杯茶。安静倒茶、看茶安顿下来，两杯都留在她身边。不递茶，也不等用户回应。 |

## 测试入口

1. 从右键菜单打开「番茄钟」，开始专注。已开始的短动作先演完；坐在窗沿时在同一落点接动作，不会为专注自动跳到别处。
2. 在桌面上开始，两套着装均分别检查站到坐的过渡。暂停时保留进度；继续时接着做；提前结束时没有完成表现。
3. 在主副屏之间点窗口，确认计时不受影响。从窗沿下到桌面后，换用场景对应的动作。现有全屏隐藏、菜单和交互优先。
4. 到点时不弹专注气泡或托盘通知。便签到期行为不变。
5. 新动作画面中的人物和道具均是完整画帧。桌面版本及窗沿版本单独绘制，注册仅调整整帧的透明留边与落点。Steve 不采用生图候选，而用原版几何重绘。

素材用 OpenAI 图像生成工具重新绘制。史蒂夫的煤矿、煤炭和前期裂纹贴图从经过 SHA-1 核验的 1.8 客户端中提取。可运行 `python tests/check-focus-companion-art.py` 复核全部图集，也可通过运行 `tests/run-focus-companion.ps1`，并可编译 `MineShift.cs` 与 `MineShiftChecks.cs` 复核状态转移。

## 史蒂夫的半小时

这不是把一段挖矿循环起来。30 分钟由 72 个长短不一的探矿片段组成，含路线、找矿、走过、观察、挖掘和安静张望。三个场景有 18 种组合；相邻片段不重复地图，完全相同的组合至少隔开八段。稀有矿可能不出现。静默、暂停和未呈现时不向前跳帧，不要求用户回应。


### 行走过渡与休整

同一小段保留固定地形和矿种。休整分别有抬头看洞顶、往回看路、低头看镐三种完整动作，每段顺序可变，不一直重复同一个摇头动作。切到下一个洞之前，史蒂夫会真正走入洞口，最后由固定石柱遮住角色；下一张图在休整期提前读入。

本版采用原来逐帧加载的性能优化。走过普通石壁时停留短；探查会多留一会儿；开采和收集之后还有完整的离场动作。不同片段按实际出洞时间预读下一洞。矿道设计覆盖完整 30 分钟，不改变番茄钟的时长设置，也不加开关。
